# STEP 02 관리자 대시보드 검증 기록

STEP 02는 플레이어 엔진을 새로 만드는 작업이 아닙니다. 기존 재생 API를 관리자가 화면에서 확인하고 조작할 수 있도록 관리자 페이지를 구성하는 작업입니다.

## 화면에서 확인할 것

1. 관리자 계정으로 로그인해 `/admin`으로 이동합니다.
2. 상단 제목이 `관리자 운영 대시보드`인지 확인합니다.
3. 관리 메뉴 바로가기로 재생 현황, 신청곡 승인, 플레이리스트, 자동 스케줄 영역을 이동합니다.
4. 재생, 일시정지, 정지, 다음 곡 버튼을 누른 뒤 화면의 상태가 바뀌는지 확인합니다.
5. 볼륨과 음소거를 조절하고 표시값이 갱신되는지 확인합니다.
6. `상태 새로고침`을 눌러 재생 상태가 다시 조회되는지 확인합니다.
7. 브라우저 폭을 줄였을 때 버튼과 메뉴가 겹치지 않고 조작 가능한지 확인합니다.

## 코드 역할

- `templates/admin/dashboard.html`: 관리자 화면의 구조와 문구
- `static/dashboard.js`: 기존 재생 API 호출과 화면 상태 갱신
- `static/styles.css`: 데스크톱·모바일 화면 배치
- `tests/test_main.py`: 관리자 화면의 필수 요소와 기존 API 동작 보호
